# 初始知识库交付说明

本交付包包含截至打包时的初始知识库快照。安装时选择“完整安装”后，快照会复制到当前 Windows 用户的 `%LOCALAPPDATA%\QwenRAG\data`，其中包括：

- 资料元数据数据库；
- FAISS 向量索引；
- 已发布的增量资料层及其元数据；
- 知识库清单与 SHA-256 完整性校验文件。

安装程序只会在客户机尚无知识库时写入该快照；已有客户知识库绝不会被安装、升级或卸载操作覆盖。卸载 QwenRAG 也会保留客户机数据。

## 使用前提

初始知识库由 `qwen3-embedding-0.6b`、`Qwen3-Embedding-0.6B-GGUF` 制品标识、1024 维、归一化向量构建。实施人员必须在客户机使用同一制品，并在 `deployment.json` 中保持相同的 `expected_revision`。模型名称、维度、归一化方式或制品版本不一致时，禁止直接使用此快照；应使用匹配的模型，或重新建立知识库。

## 验收

安装完成后，确认 `%LOCALAPPDATA%\QwenRAG\data\snapshot.json`、`SHA256SUMS.txt`、`metadata.db` 和 `vector_index\index.faiss` 存在。再完成模型契约检查、启动 RAG，并用已知资料进行一次检索问答。
