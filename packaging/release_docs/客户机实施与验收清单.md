# 客户机实施与验收清单

## 安装前

- [ ] 客户机满足 Windows、GPU、显存与磁盘要求。
- [ ] 安装介质的 `Setup.exe`、全部分卷和 `SHA256SUMS.txt` 齐全且哈希一致。
- [ ] 客户机未安装旧的测试版本，或已完成数据备份。

## 模型部署

- [ ] llama.cpp、Qwen3.6-27B GGUF、Qwen3-Embedding-0.6B GGUF 已离线放入客户机。
- [ ] 两个模型均只监听 `127.0.0.1`。
- [ ] `/health` 与 `/v1/models` 可用，模型别名与配置一致。
- [ ] Embedding 为 1024 维、归一化向量，且已记录制品版本或 SHA-256。

## RAG 配置与启动

- [ ] 已按客户机路径更新 `deployment.json`，未覆盖 `secrets.json`。
- [ ] `config test-models` 通过。
- [ ] 双击“启动 QwenRAG”后，安装诊断与就绪状态正常。
- [ ] Chatbox 可列出模型，并完成非流式和流式问答。

## 资料与数据保护

- [ ] 空知识库可完成 TXT、DOCX、PDF 和扫描 PDF 入库。
- [ ] 有初始知识库时，检索结果与参考文件正常。
- [ ] 关闭启动窗口后，本次拉起的服务停止；预先运行的模型服务不受影响。
- [ ] 修复安装、升级、卸载和重装后，配置、知识库、归档和结果仍保留。

## 交付确认

- [ ] 已向客户说明日常启动、停止、资料入库和问题反馈方式。
- [ ] 已移交安装介质、模型部署说明、用户使用说明和故障排查手册。
- [ ] 已保存验收日期、实施人员、模型制品版本和验收结果。
