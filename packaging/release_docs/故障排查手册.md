# QwenRAG 故障排查手册

| 现象 | 优先检查 | 处理原则 |
| --- | --- | --- |
| 找不到模型程序 | `deployment.json` 中的程序与工作目录 | 改为客户机本地绝对路径，不使用开发机或服务器路径。 |
| 端口被占用 | 8001、8002、8010、18080 | 不要强制结束未知进程；先确认是否为可复用的正确模型服务。 |
| 模型加载超时 | GPU 驱动、模型路径、显存、启动参数 | 单独启动模型并检查 `/health` 与 `/v1/models`。 |
| Embedding 维度或版本不匹配 | 模型别名、1024 维、`expected_revision` | 停止使用该知识库；更换 Embedding 后必须重建知识库。 |
| 知识库损坏 | 安装诊断、日志、磁盘状态 | 保留原数据与日志，不要覆盖；由实施人员恢复备份或重建。 |
| OCR 模型缺失 | 程序目录下 `resources\ocr` | 重新使用完整安装介质进行修复安装。 |
| Chatbox 返回 401 | 地址、模型名、API Key | 使用实施人员提供的本机地址和密钥，不要把密钥发送给无关人员。 |
| Chatbox 返回 502/503/504 | 模型服务、网关、RAG 日志 | 先运行模型契约检查和安装诊断，再收集日志。 |
| 关闭窗口后服务残留 | 启动窗口、日志、端口 | 记录残留端口和日志，交由实施人员处理；不要结束未知模型服务。 |

日志位置：`%LOCALAPPDATA%\QwenRAG\logs`。资料入库结果位于资料入库工作台的“02_查看处理结果”。
