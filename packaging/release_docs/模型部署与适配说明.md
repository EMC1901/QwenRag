# QwenRAG 模型部署与适配说明

## 交付边界

QwenRAG 安装包不包含模型权重、GGUF 文件、llama.cpp 或 Chatbox。实施人员应在客户机离线部署以下两项本地服务：

- Qwen3.6-27B GGUF（Q4_K_M）LLM 服务；
- Qwen3-Embedding-0.6B GGUF Embedding 服务。

服务只监听客户机回环地址 `127.0.0.1`，不得暴露到局域网或互联网。

## 推荐目录

建议在客户机非系统盘使用以下结构，实际盘符可调整：

```text
D:\QwenRAG\
├── llama.cpp\
│   └── llama-server.exe
└── models\
    ├── Qwen3.6-27B-Q4_K_M.gguf
    └── Qwen3-Embedding-0.6B.gguf
```

## 服务约定

| 服务 | 端口 | 模型别名 | 关键要求 |
| --- | --- | --- | --- |
| LLM | 8001 | `qwen3.6-27b` | OpenAI 兼容聊天接口 |
| Embedding | 8002 | `qwen3-embedding-0.6b` | OpenAI 兼容 Embeddings 接口，1024 维、归一化向量 |

示例启动命令（按实际 llama.cpp 版本和 GPU 情况调整）：

```powershell
D:\QwenRAG\llama.cpp\llama-server.exe -m D:\QwenRAG\models\Qwen3.6-27B-Q4_K_M.gguf --host 127.0.0.1 --port 8001 --alias qwen3.6-27b -c 8192 --n-gpu-layers 99

D:\QwenRAG\llama.cpp\llama-server.exe -m D:\QwenRAG\models\Qwen3-Embedding-0.6B.gguf --host 127.0.0.1 --port 8002 --alias qwen3-embedding-0.6b --embedding --pooling last --embd-normalize 2 --n-gpu-layers 99
```

## 配置 QwenRAG

1. 安装 QwenRAG，首次安装会生成 `%LOCALAPPDATA%\QwenRAG\config\deployment.json` 与 `secrets.json`。
2. 将随包 `deployment.customer.example.json` 的非秘密字段与客户机实际路径、模型文件名、端口和别名对齐。
3. 不要覆盖或手工发送 `secrets.json`。
4. 初始知识库交付版的 `expected_revision` 必须填写 `Qwen3-Embedding-0.6B-GGUF`；若改用其他 GGUF 制品，必须重建知识库。
5. 运行“配置与诊断工具”，再执行：

```powershell
%LOCALAPPDATA%\Programs\QwenRAG\QwenRagRuntime.exe config test-models
```

## 服务验收

在客户机上确认以下接口可用：

```powershell
curl.exe http://127.0.0.1:8001/health
curl.exe http://127.0.0.1:8001/v1/models
curl.exe http://127.0.0.1:8002/health
curl.exe http://127.0.0.1:8002/v1/models
```

之后运行已安装的 `QwenRagRuntime.exe config test-models`。只有模型名称、Embedding 维度、归一化方式和制品版本均符合要求时，才允许启动 RAG 或进行资料入库。

## 更换模型

更换 LLM 后，应重新执行模型契约检查。更换 Embedding 模型、量化制品或版本后，必须重建知识库；即使模型名称和向量维度相同，也不能假定向量空间兼容。
