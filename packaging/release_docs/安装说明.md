# QwenRAG 安装说明

## 适用范围

本安装介质仅包含 QwenRAG、OCR 和资料入库运行环境。不包含 Qwen 大语言模型、Qwen3-Embedding-0.6B、GGUF 模型文件、llama.cpp 或 Chatbox；这些内容由实施人员在客户机离线部署。

## 安装前确认

- Windows 10 或 Windows 11，64 位。
- 建议使用 NVIDIA GPU，显存与磁盘空间满足部署的模型要求。
- 将 `QwenRAG-*-Setup.exe` 与同目录所有 `QwenRAG-*-Setup-*.bin` 文件放在同一个本地目录。缺少任一分卷都不能安装。
- 使用 `SHA256SUMS.txt` 核对所有交付文件；哈希不一致时不要继续安装。

## 安装

1. 双击 `QwenRAG-*-Setup.exe`。
2. 保持默认的当前用户安装目录即可。
3. 如介质提供“初始知识库”，可按项目要求选择；未选择时系统会创建可直接入库的空知识库。
4. 安装完成后，由实施人员按《模型部署与适配说明》配置客户机本地模型。

程序安装位置为 `%LOCALAPPDATA%\Programs\QwenRAG`。用户配置、知识库、资料入库工作台、处理结果和日志位于 `%LOCALAPPDATA%\QwenRAG`。

## 数据保留与升级

- 同版本修复安装和版本升级会更新程序，不覆盖用户知识库、资料、结果和日志。
- 升级前会保留配置备份。
- 卸载仅删除程序和快捷方式，默认保留 `%LOCALAPPDATA%\QwenRAG` 下的所有用户数据。

## 安装失败时

请不要删除用户数据。收集以下信息交给实施人员：安装器提示、`%LOCALAPPDATA%\QwenRAG\logs`、安装器日志，以及 `SHA256SUMS.txt` 核验结果。
