# QwenRAG 用户使用说明

## 日常使用

1. 双击开始菜单或桌面的“启动 QwenRAG”。
2. 保持出现的 PowerShell 窗口打开；看到“已就绪”后即可使用 Chatbox。
3. 在 Chatbox 中使用实施人员提供的本机地址、模型名称和 API Key。

关闭启动窗口或按 `Ctrl+C` 会停止本次启动的 QwenRAG 服务。请在确认不再使用后再关闭。

## 导入资料

1. 先退出 QwenRAG。
2. 打开“资料入库工作台”。
3. 将 PDF、Word、TXT 或扫描 PDF 放入“01_请把新资料放这里”。
4. 双击“开始资料入库”，等待结果写入“02_查看处理结果”。
5. 成功处理的原始资料会进入“03_已处理资料归档”。

资料入库期间不要关闭窗口，也不要同时启动 QwenRAG。

## 出现问题时

请记录屏幕提示，并将 `%LOCALAPPDATA%\QwenRAG\logs` 和资料工作台中的结果文件交给实施人员。不要自行删除知识库、配置或归档资料。
